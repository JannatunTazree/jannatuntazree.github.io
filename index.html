03 — Data Analytics Project

Fake News Analysis

📊 Power BI  ·  Multimodal Research Dataset

A comprehensive data analytics project exploring fake news patterns using an annotated multimodal dataset. Each record contains the article title, full content, source, publication date, claim type, contextual metadata, and a final human-verified decision label — enabling rich cross-dimensional analysis.

The dataset supports both textual and visual research workflows: image paths are included for multimodal machine learning experiments. The Power BI dashboard uncovers patterns across claim types, source credibility, temporal trends, and label distribution.

Dataset Schema

Field Type Description
title Text Headline or title of the news article / claim
content Text Full body text of the article or statement under review
source Text Publication or platform where the content originated
date Date Publication or verification date — supports temporal trend analysis
claim_type Category Nature of the claim (e.g. health, politics, science, social media)
context Text Additional background metadata for fact-checking decisions
final_decision Text Human-verified verdict used as ground truth for the label
summary Text Short annotator summary of the fact-checking outcome
label Enum (8) Classification target — False / Misleading / Altered / Scam / Satire / True / Partially True / Partially False
image_path Path File reference to associated image for multimodal research pipelines
📈
Label Distribution
Donut and bar charts showing the proportion of each of the 8 label categories — revealing class imbalance and dominant misinformation types in the dataset.
🗓️
Temporal Trends
Line chart mapping publication dates against label volume — exposing spikes in fake news production around specific events or time periods.
📰
Source Credibility
Matrix visual ranking sources by their ratio of false / misleading content, helping identify outlets with consistently low fact-check scores.
🏷️
Claim Type Analysis
Stacked bar chart cross-referencing claim type (health, politics, etc.) against label — showing which domains generate the most Scam or Altered content.
🖼️
Multimodal Coverage
Visual metric tracking what percentage of records include an associated image path — quantifying multimodal dataset completeness for ML use cases.
⚖️
Decision vs. Label
Comparison table aligning the free-text final_decision with the structured label — useful for auditing annotation consistency across reviewers.
