# Jannatun Tazree — Portfolio Website

Personal portfolio website ready for GitHub Pages hosting.

## 🚀 Deploying to GitHub Pages

### Option A — Personal site (username.github.io)
1. Create a GitHub repository named exactly `<your-username>.github.io`
2. Upload **all files and folders** from this zip to the root of the repository
3. Go to **Settings → Pages** → Source: **Deploy from branch** → Branch: `main` → Folder: `/ (root)`
4. Your site goes live at `https://<your-username>.github.io`

### Option B — Project site
1. Create any GitHub repository (e.g. `portfolio`)
2. Upload all files to root
3. Go to **Settings → Pages** → same as above
4. Live at `https://<your-username>.github.io/portfolio`
